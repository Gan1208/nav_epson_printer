# 送貨單 list（取代下拉）+ 執貨單字 + logo

Status: confirmed

先完成同 commit `.scratch/whole-day-print/spec.md`，再做呢份。

## 首頁

- 日期、類別照舊。下面加「查詢」掣。
- 唔再自動載入。撳「查詢」先載入。
- 轉日期或者類別：清走 list 同所有剔，要再撳「查詢」。
- 送貨單 下拉同「全日」拎走，改用 list。
- 載入中、連線失敗（+「重試」）、沒有送貨單：同以前一樣嘅字。

## List

- 次序：送貨單號 由細到大。
- 每行一個剔。一行顯示：
  ```
  ☐ 1799**   王小明   牛奶
     SO-12345, SO-12346
  ```
  - 送貨單號：尾四位 + `**`（同以前一樣）。
  - 客人名稱：同 收據 上面嘅 Name 一樣（第一張 訂單 嘅 Ship-to Name）。
  - 類別：細字「牛奶」/「雪糕」。
  - 訂單號：呢張 送貨單 所有 訂單，逗號分開，太長轉行。
- 頂部「全選」。一開始乜都冇揀。
- 由預覽返轉頭，剔保留。

## 預覽

- 底部掣：「預覽（N 張）」。冇揀就灰咗。
- 揀 1 張 → 單張預覽（有「只打印此頁」）。
- 揀 2 張或以上 → 用 whole-day-print spec 嗰個多張預覽同打印流程（N 張、停止、失敗重試、返回確認）。

## 收據 改動

- 執貨單 所有字放大 1.5 倍：`22.sp` → `33.sp`，行距 `30.sp` → `45.sp`。QR code 大細唔變。
- 回單、客戶單 logo：`154.dp` → `231.dp`。執貨單 冇 logo。
