# 收據打印 (Receipt print)

Status: confirmed

## 目標

喺 收據 預覽頁按「打印」，經公司 wifi 喺固定嗰部 Epson TM-m30II 印出揀中 送貨單 嘅三頁，格式同大小同預覽一模一樣。

## 範圍

- 只印預覽緊嗰 **一張** 送貨單。
- 不做一次印全日所有單。
- 不記錄邊張 送貨單 印咗；印兩次都唔攔。

## 打印機

- Epson TM-m30II，80mm 熱敏紙，可印寬度 576 dots。
- 經公司 wifi 連接。IT 喺 router 幫打印機固定一個 IP。
- 用 Epson ePOS SDK for Android 2.37.1 連接（由 `download-center.epson.com` 下載，唔喺 Maven）。
  - `app/libs/ePOS2.jar`，`app/src/main/jniLibs/{arm64-v8a,armeabi-v7a,x86_64}/libepos2.so`。
  - EULA 規定要同 SDK 一齊附上：`app/libs/EULA.en.txt`。
  - `ePOS2.jar` 冇數碼簽名；來源已核實係 Epson 伺服器（HTTPS，證書屬 SEIKO EPSON Corporation）。

## 打印

- 預覽頁頂有一個大「打印」掣。首頁唔可以直接印，一定要先入預覽。
- 按一下，依次印 `回單` → `執貨單` → `客戶單`。
- 每個 tab 另有「只印呢頁」，用嚟補印單一頁。
- 每頁畫成一張 576 dots 闊嘅黑白圖片送去打印機，唔用打印機字體。即係預覽同紙上一模一樣（中文、logo、QR code）。
- 每頁之後半切（partial cut）。
- 一次打印（三頁或者一頁）包成一單送去，唔會同其他手機嘅頁夾埋。

## 共用

- 大概 3 部手機共用同一部打印機。
- 打印機忙緊（其他手機印緊），自動再試，最多大概 10 秒；仲係忙就當出錯。

## 出錯

- 打印失敗就彈出原因，例如：冇紙、蓋打開咗、連唔到打印機、打印機忙。
- 打印機 5 秒冇回應就當連唔到。（SDK 自己嘅 connect 喺冇回應時會等兩分幾鐘，唔理佢自己個 timeout。）
- 俾一個「重印全部三頁」掣（「只印呢頁」失敗就重印嗰一頁）。
- 唔做「只印未出嘅頁」。

## 設定頁

- 首頁右上角齒輪入。
- 一欄：打印機 IP。打一次就記住。
- 「測試打印」掣：印一張細紙，確認連到。
  - 印之前先用 Epson `Discovery` 喺 wifi 搵嗰個 IP 嘅打印機型號，最多 5 秒。期間掣上顯示「搜尋打印機中…」。
  - 搵完彈框，兩個掣：「打印」、「取消」。撳「取消」就唔印。
    - 搵到：「找到打印機 TM-m30II（192.168.1.50）。確定打印測試頁？」
    - 型號唔同：「此 IP 的打印機型號為 XXX，不是 TM-m30II。仍要打印測試頁？」
    - 搵唔到：「找不到此 IP 的打印機型號。仍要打印測試頁？」
  - 型號名以 `TM-m30II` 開頭就當啱（例如 `TM-m30II-H`）。
  - 搵唔到或者型號唔同都照俾印：有啲 wifi 會擋住搜尋。
  - 印 送貨單 時唔搵、唔彈框。
- 唔使密碼。

## 用字

- app 入面所有字用書面語，唔用口語。包括現有嘅出錯訊息，例如「連唔到打印機」改做「無法連接打印機，請檢查打印機是否已開啟，以及手機是否已連接公司 wifi」。
