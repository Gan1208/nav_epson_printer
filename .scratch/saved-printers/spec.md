# 已儲存打印機

Status: confirmed

## 加入清單

- 測試打印冇出錯（顯示「已送出測試打印」）先加入清單。
- 新打印機加入：即刻彈框「打印機名稱」（例如「倉庫」）。可以留空：留空就顯示 IP。
- 同一個 IP 再成功：搬去最頂，唔會出兩次，唔再問名，名照舊。型號用最新嗰次。
- 最新成功嘅喺最頂。最多 10 部：第 11 部加入，最底嗰部會冇咗。
- 兩部打印機可以同名：下面有 IP 分得開。

## 設定頁清單

- 喺 IP 格同掣下面，標題「已儲存打印機」。
- 每行：名大字，下面細字 `IP · 型號`（搵唔到型號就淨係 IP）。
- 而家用緊嗰部前面有 ✓。
- 撳一行：填入 IP，即刻變成用緊嗰部，唔使再撳「儲存」。
- ✎：改名。
- ✕：問「確定刪除？」先刪。刪咗用緊嗰部都照用嗰個 IP，只係冇咗 ✓。
- 搵緊或者印緊：清單撳唔到。

## 預覽頁

- 「打印」掣上面顯示「打印機：倉庫」。冇名就顯示 IP。冇設定 IP 就顯示「未設定打印機」。
- 同一張 送貨單 同多張打印都一樣。

## 打印

- 一次只印去一部：用緊嗰部。清單只係用嚟揀。
